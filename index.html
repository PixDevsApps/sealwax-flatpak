Sealwax Flatpak repository

Sealwax 1.6.3, the email client, as a Flatpak for Linux distributions other than Omarchy and Arch. On Omarchy, install the Arch package instead: see INSTALL.md.

Install it, and the GNOME runtime it needs from Flathub, with one line:

flatpak install --user https://github.com/PixDevsApps/sealwax/releases/latest/download/io.github.pixdevsapps.Sealwax.flatpakref

Updates then come with flatpak update, or from GNOME Software or KDE Discover. The repository on its own: sealwax.flatpakrepo; the file the line above fetches is here too.
